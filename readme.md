# 🚀 Matrix Task Board (0.5h Unit)

「0.5時間（30分）」を1つの最小単位（ブロック）として、プロジェクトの進捗を視覚的に管理するためのWebベースのタスク管理ツールです。

## 🌟 特徴

- **30分単位のブロック管理**: 大きなタスクを自動的に0.5h単位のブロックに分割。着手ハードルを下げ、見積もり精度を向上させます。
- **マトリックス形式のレイアウト**: 縦軸に「プロジェクト」、横軸に「工程（調査〜完了）」を配置し、全体像を一目で把握できます。
- **ドラッグ＆ドロップ操作**: 直感的にマウスでブロックを掴んで、工程間を移動させることが可能です。
- **柔軟なステータス管理**: 各ブロックを右クリックすることで、状態（進行中、ペンディング、後回し、手つかず）に応じて色が変化します。
- **自由入力の進捗率**: システムの自動計算に頼らず、責任者が現場の感覚に合わせて進捗（%）を直接入力できます。
- **完全ローカル保存**: ブラウザの LocalStorage を使用しているため、サーバー不要でデータはあなたのブラウザに安全に保存されます。

## 📋 使い方

### 1. タスクの登録
1. 画面上部の「プロジェクト名」と「タスク内容」を入力します。
2. そのタスクにかかる「合計工数（h）」を入力します。
   - 例：`2.0` と入力すると、`0.5H` のブロックが **4個** 生成されます。
3. 「投入」ボタンを押すと、一番左の「調査」カラムにブロックが追加されます。

### 2. 工程の移動
- ブロックをマウスでドラッグし、隣の工程（例：企画 → 開発）へドロップしてください。
- 「完了」カラムに移動したブロックは、自動的に **緑色** に変化します。

### 3. ステータス（色）の変更
- 各ブロックを **右クリック** すると、色が以下の順でループします。
  - 🔵 **青 (Doing)**: 現在進行中の作業
  - 🔴 **赤 (Pending)**: 課題があり停止中の作業
  - 🟠 **オレンジ (Later)**: 優先度を下げ、後回しにしている作業
  - ⚪ **グレー (Todo)**: まだ手をつけていない作業

### 4. 進捗率の更新
- プロジェクト名横の数値入力欄に、現在の進捗状況（0〜100）を直接入力してください。

## 🛠 技術仕様

- **言語**: HTML5, CSS3, JavaScript (Vanilla JS)
- **保存機能**: ブラウザ LocalStorage API
- **ライブラリ**: なし（標準機能のみで動作するため、非常に軽量です）

## 🚀 セットアップ（開発者向け）

特別なインストール作業は不要です。

1. `index.html` （作成したコード）を保存します。
2. お好きなブラウザ（Chrome, Edge, Firefoxなど）でそのファイルを開くだけで利用可能です。

## 🎨 色の凡例

| 色 | 状態 | 意味 |
| :--- | :--- | :--- |
| 🔵 青 | 進行中 | 現在リソースを割いているアクティブなタスク |

| 🟢 緑 | 完了 | 「完了」列に移動した済みのタスク |
